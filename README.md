# MH Collections - Modern E-Commerce Storefront 🛍️✨

A full-featured responsive online shopping platform built with **React**, **Tailwind CSS**, and **Firebase** (Firestore & Auth).

---

## 🌟 Key Features

- **Product Catalog & Details**: Browse clothing, collections, and seasonal arrivals with interactive detail views.
- **Cart & Seamless Checkout**: Easy-to-use cart management and checkout flow.
- **Order Tracking**: Real-time order status tracking directly integrated with Firestore.
- **Admin Inventory Portal**: Protected admin dashboard for managing stocks, adding new items, and tracking orders.

---

## 🛠️ Installation & Setup

1. **Clone the repository**:
   ```bash
   git clone https://github.com/oyan2010/mh-collections-client.git
   cd mh-collections-client
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Configure Environment Variables**:
   Copy `.env.example` to `.env`:
   ```bash
   cp .env.example .env
   ```
   Add your Firebase project configuration credentials.

4. **Run the App**:
   ```bash
   npm run dev
   ```
